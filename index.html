개인용 Windows 일정·할 일 관리 앱입니다. 오늘 할 일, 프로젝트, 타이머, 기한, 통계를 한 PC 안에서 관리합니다. 모든 데이터는 사용자의 PC에만 저장됩니다.

구글 캘린더 연동 (선택)

사용자가 설정에서 직접 연결했을 때만 동작합니다.

  • 앱이 만든 「Schedule App」 캘린더에 일정을 보냅니다.
  • 사용자가 고른 캘린더의 일정을 읽어 앱 화면에 보여 줍니다(보기 전용).
  • (선택) 「동기화」(두 PC 동기화)를 켜면 앱 데이터를 사용자 본인 구글 계정의 「Schedule App Data」 캘린더에 보관해 다른 PC와 맞춥니다.
  • 메일, 드라이브, 연락처 등 다른 구글 데이터에는 접근하지 않습니다.

English

Schedule is a personal Windows app for daily tasks, projects, timers and deadlines. All data stays on the user's own PC. Google Calendar sync is optional and works only after the user connects it in Settings: the app writes events to a calendar it creates ("Schedule App"), reads events from calendars the user picks, for display only, and, only if the user turns on two-PC sync, keeps the app data in another calendar it creates in the user's own Google account ("Schedule App Data") to match it between the user's PCs. It does not access Gmail, Drive, contacts or any other Google data.
