1. 읽는 정보

사용자가 설정 › 구글 캘린더에서 연결했을 때만, 다음 권한(범위)으로 구글 캘린더에 접근합니다.

  • calendar.calendarlist.readonly: 캘린더 목록(이름)을 읽어, 가져올 캘린더를 고를 수 있게 합니다.
  • calendar.events.readonly: 사용자가 고른 캘린더의 일정(오늘 기준 약 35일 전 ~ 100일 뒤)을 읽어 앱에 보여 줍니다.
  • calendar.app.created: 앱이 만든 「스케줄 앱」 캘린더에만 일정을 쓰고 고칩니다. 다른 캘린더에는 쓰지 않습니다.

2. 저장 위치

  • 읽은 일정은 사용자 PC의 앱 데이터 파일(로컬 데이터베이스)에만 저장합니다.
  • 로그인 정보(refresh token)는 Windows 자격 증명 관리자에 저장하며, 데이터 파일이나 백업에는 넣지 않습니다.
  • 개발자나 다른 서버로 보내지 않습니다. 광고, 분석, 판매, AI 학습에 쓰지 않습니다.

3. 공유

누구와도 공유하지 않습니다. 구글 API와 주고받는 통신만 있습니다.

4. 지우는 방법

  • 앱 설정 › 구글 캘린더 › 연결 끊기: 로그인 정보를 지우고 구글에 권한 취소를 요청합니다.
  • 구글 계정의 서드 파티 액세스에서도 언제든 권한을 취소할 수 있습니다.
  • 앱 데이터 파일(%APPDATA%\com.kairo.schedule)을 지우면 가져온 일정도 모두 지워집니다.

5. Google API 서비스 사용자 데이터 정책

이 앱이 구글 API에서 받은 정보를 사용하고 다른 앱으로 옮기는 방식은 Google API Services User Data Policy(제한적 사용 요건 포함)를 따릅니다.

English

Only after the user connects Google Calendar in Settings, the app uses: calendar.calendarlist.readonly (list calendar names so the user can choose), calendar.events.readonly (read events from the chosen calendars, about 35 days back to 100 days ahead, shown in the app read-only), and calendar.app.created (create and update events only in the calendar the app itself creates). Event data is stored only in the local database on the user's PC; the login token is kept in Windows Credential Manager. No data is sent to the developer or any other server, and none is shared, sold, used for ads, analytics or AI training. To delete: Settings › Google Calendar › Disconnect (removes the token and asks Google to revoke it), or revoke at Google Account › Third-party access, or delete the app data folder. The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
